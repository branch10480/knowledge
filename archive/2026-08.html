最新ベータ版リリースへの対応準備

2026-08-04 Appleベータ版iOSiPadOSmacOStvOSvisionOSwatchOSXcode開発者

Appleは2024年12月16日、iOS 18.3、iPadOS 18.3、macOS 15.3、tvOS 18.3、visionOS 2.3、watchOS 11.3のベータ版を公開しました。開発者には、これらのリリースでアプリが期待通り動作することを確認し、Xcode 16.2でビルドとテストを行って最新SDKの利点を活用するよう求めています。ダウンロード、リリースノート、ベータOSのテスト方法、フィードバック送信に関する情報が提供されています。

App Storeの特集掲載プロセスの拡張：Featuring Nominationsとマーケティングアセットの新機能

2026-08-04 App StoreApp Store ConnectFeaturing Nominations開発者マーケティング

Appleは2024年11月12日、App Storeの特集掲載プロセスを拡張し、App Store Connectで新たに「Featuring Nominations」を導入しました。開発者はアプリやゲームの新規リリース、アプリ内コンテンツ、追加機能などをノミネートして特集掲載を申請できます。Todayタブなどの特集掲載に選ばれた場合、App Store Connectアプリで通知を受け取れます。また、アプリのローンチや新バージョンなどの重要な瞬間を宣伝するための、AppleがデザインしたマーケティングアセットをApp Store Connectアプリで生成し、ソーシャルメディアで共有できます。アセットにはApp Storeでアプリをダウンロードできるリンクを含めることができます。

Advanced Commerce API の導入

2026-08-04 AppleApp StoreAPIアプリ内課金コマース

Apple は、App Store の取引をさらに柔軟に管理できる新しい Advanced Commerce API を発表しました。この API は、大規模なコンテンツカタログ、クリエイター向けエクスペリエンス、オプションのアドオンを備えたサブスクリプションなど、進化するビジネスモデルをサポートします。開発者は申請を通じて利用でき、エンドツーエンドの決済処理、税務サポート、カスタマーサービスなど、信頼される App Store のコマースシステムを活用しながら、アプリ内課金をより柔軟に管理できます。

アプリ、App内課金、サブスクリプションの価格と税制の更新（2024年11月14日）

2026-08-04 AppleApp Store価格更新税制VATApp内課金サブスクリプション

Appleは2024年11月14日、App Storeにおけるアプリ、App内課金、サブスクリプションの価格と税制の更新を発表しました。10月時点の税制変更として、ネパールとカザフスタンではAppleが現地開発者向けにVAT（付加価値税）を納付しなくなり、開発者の収益が増加。マデイラでは新聞・雑誌・書籍・オーディオブックのVAT率が5%から4%に引き下げられました。12月2日からは、日本とトルコのストアフロントを基準にしていないアプリとApp内課金の価格が更新されます。基準として選択している場合は価格は変更されません。自動更新サブスクリプションや手動価格管理を行っているストアフロントでは価格は変わりません。App Store Connectの価格と提供状況セクションで今後の価格変更を確認できます。

欧州経済領域・英国・米国における規制対象医療機器アプリの表示更新

2026-08-04 AppleApp Store医療機器規制欧州経済領域英国米国

Appleは、欧州経済領域（EEA）、英国、米国において、App Storeの製品ページに規制対象医療機器アプリであることを表示することを発表しました。対象となるアプリは、診断・予防・モニタリング・治療などの医療目的で機能するもので、FDAなどの規制当局による登録や承認が必要となる場合があります。開発者はApp Store Connectで規制対象医療機器ステータスと関連する規制情報（連絡先や安全情報など）を提供する必要があります。新規アプリは本日から必須、既存アプリは2027年初頭までに提供する必要があり、期限までに提供しない場合はアプリのアップデート提出ができなくなります。
