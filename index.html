OpenAI、GPT-5.6 モデルファミリーを発表（Sol / Terra / Luna）

2026-07-09AIOpenAIGPT

OpenAI は新しいモデルファミリー GPT-5.6 を発表しました。3つのバリアントを展開：Sol（ワークホース）、Terra（中間）、Luna（低コスト）。CEO Sam Altman によれば Sol はコード生成タスクで 54% のトークン効率改善を達成。同社史上「最も強力なサイバーセキュリティモデル」と位置づけられ、脅威モデリング、コードレビュー、パッチ適用、ブルーチーム演習をサポート。新ツール ChatGPT Work も同時リリース。価格は Sol $5/$30、Terra $2.50/$15、Luna $1/$6（100万トークンあたり）。OpenAI は Coding Agent Index ベンチマークで Sol が Anthropic Fable を上回ったと主張。

Apple、WWDC 2026 Platforms State of the Union で AI・開発者ツールの大幅更新を発表

2026-06-09AppleWWDCAISwiftXcodeSwiftUI

Apple は WWDC 2026 の Platforms State of the Union で Foundation Models フレームワークの無料提供（Private Cloud Compute 経由）、オープンソース化（今夏）、画像入力サポート、サーバーサイドモデル統合（Claude/Gemini を Swift API から呼び出し可能）を発表。Xcode 27 は 30% 小型化・Apple Silicon 専用に、Swift 6.4 では anyAppleOS 省略記法・コンパイラ警告抑制・defer ブロックでの async 対応などが追加。Liquid Glass の強制移行、Intel Mac の完全非推奨化、Game Porting Toolkit の AI スキル拡充、MLX の Metal 4 対応と RDMA による Mac 間分散学習も発表。Notion が SwiftUI への移行を表明したことも注目点。
