OpenAI、GPT-5.6 モデルファミリーを発表（Sol / Terra / Luna）

2026-07-09 AIOpenAIGPT

OpenAI は新しいモデルファミリー GPT-5.6 を発表しました。3つのバリアントを展開：Sol（ワークホース）、Terra（中間）、Luna（低コスト）。CEO Sam Altman によれば Sol はコード生成タスクで 54% のトークン効率改善を達成。同社史上「最も強力なサイバーセキュリティモデル」と位置づけられ、脅威モデリング、コードレビュー、パッチ適用、ブルーチーム演習をサポート。新ツール ChatGPT Work も同時リリース。価格は Sol $5/$30、Terra $2.50/$15、Luna $1/$6（100万トークンあたり）。OpenAI は Coding Agent Index ベンチマークで Sol が Anthropic Fable を上回ったと主張。

Anthropic、Claude Opus 4.8 をリリース — コード・エージェント・プロフェッショナル性能が向上

2026-05-28 AIAnthropicClaude

Anthropic は Claude Opus 4.8 をリリース。Opus 4.7 からのアップグレードで、コーディング、エージェントタスク、専門的ワークのパフォーマンスが向上。新機能として claude.ai 上の Effort Control（応答品質の調整）、Claude Code の Dynamic Workflows（大規模タスクの並列サブエージェント処理）、Fast Mode（2.5倍速・3倍安価）を同時提供。価格は従来据え置き（入力 $5/100万トークン、出力 $25/100万トークン）。Honesty（正直性）の向上も顕著で、コードの欠陥を無警告で通す率が約4分の1に低減。Project Glasswing として Mythos クラスモデルの一般公開準備も進行中。
